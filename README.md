# 2026-09-16-matlab-hcc
AI and Parallel Computing with MATLAB® Training @ UNL

This repository contains the data files used for the **Deep Learning on the Cluster: An AI workflow example using Open OnDemand** Section of the **AI and Parallel Computing with MATLAB® Training @ UNL** hosted by the [Holland Computing Center (HCC)](https://hcc.unl.edu/) at the **University of Nebraska–Lincoln** on 09/16/2026. Whether you're following along during the event or exploring the materials afterward, this repo will help you replicate the examples, practice hands-on exercises, and build upon what you’ve learned.

For more information about the workshop, visit: [Parallel and AI Computing with MATLAB® (taught by MathWorks® engineers)](https://hcc.unl.edu/parallel-and-ai-computing-matlab%C2%AE-taught-mathworks%C2%AE-engineers).
